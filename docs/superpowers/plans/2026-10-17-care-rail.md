# Care Rail Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Добавить после бестселлеров бесконечную интерактивную золотую рельсу с уходовыми продуктами и связанной информационной панелью.

**Architecture:** Новый модуль `care-rail.js` владеет данными выбранных продуктов, бесшовной прокруткой, drag-жестом и обновлением активной карточки. `index.html` содержит доступный каркас секции, а `styles.css` отвечает за champagne-gold сцену и адаптив. Реальные фото «до/после» и hair-продукты остаются отдельным расширением, потому что исходных материалов сейчас нет.

**Tech Stack:** HTML, CSS, native ES modules, Pointer Events, `requestAnimationFrame`, Node test runner.

**Spec:** `docs/superpowers/specs/2026-10-17-care-rail-design.md`

## Global Constraints

- Использовать только предоставленные пользователем PNG без фона; не изменять упаковку и надписи.
- Подчеркнуть корейское происхождение ухода в заголовке и подписи секции.
- Не генерировать фиктивные результаты «до/после».
- Не добавлять зависимости.
- Уважать `prefers-reduced-motion` и клавиатурный фокус.
- Сохранить текущий порядок: «Бестселлеры» → beauty-рельса → «Реальные отзывы».

## Review Focus

- Нулевая или ещё не измеренная ширина сегмента не должна приводить к `NaN` или скачку.
- Повторяющиеся копии продукта не должны создавать дублируемые клавиатурные цели.
- Перетаскивание не должно случайно открывать ссылку товара.
- Переход вкладки в фон должен останавливать лишнюю анимацию и корректно продолжать её при возврате.
- На узком экране активный продукт и панель должны оставаться читаемыми без горизонтального скролла страницы.
